Self-assessment / Authorized artifacts

ทดลองกับสิ่งที่คุณ
มีสิทธิ์ประเมิน.

สร้าง fixture ของตนเอง บันทึก baseline และประเมินผลอย่างเป็นระบบ หน้านี้ไม่อ้างผล challenge หรือผลทดลองจากโครงการต้นทาง

  1. 01

    เตรียม fixture

    เลือกโปรแกรมตัวอย่างที่ไม่มีความลับจริง เก็บ source, build ต้นฉบับ และ functional tests ไว้ครบ

  2. 02

    บันทึก audit และ defend

    axobfus audit ./fixture/dist --report ./reports/audit.html
axobfus defend ./fixture/dist --report ./reports/defend.html
  3. 03

    ตรวจ correctness

    รัน verify กับ output จริงและทดสอบ workload ทั้งหมด จากนั้นจึงเปรียบเทียบ analyzer ใน environment ที่ควบคุมได้

  4. 04

    เผยแพร่หลักฐานอย่างรับผิดชอบ

    ระบุ version, configuration, hardware และข้อจำกัด อย่าเผยแพร่ข้อมูลลับ และอย่าสรุปเกินกว่า analyzer ที่ทดสอบ

ขอบเขตที่ชัดเจน

การเพิ่ม decoys และ resource/semantic exhaustion ไม่ได้ทำให้ artifact ปลอดภัยจาก reverse engineering อย่างสมบูรณ์ ผลลัพธ์ขึ้นกับ artifact, analyzer และสภาพแวดล้อม

ดูตารางเก็บหลักฐานการประเมิน
