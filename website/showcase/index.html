Evaluation / ไม่มีตัวเลขสำเร็จรูป

หลักฐานของคุณ
สำคัญกว่าตัวเลขโฆษณา.

ประเมิน AxObfus กับ artifact, analyzer และ workload ของคุณเอง หน้านี้ไม่นำ benchmark หรือผล red-team ของโครงการต้นทางมาแสดงเป็นผลลัพธ์ของ AxObfus

01 / วิธีวัด

ทดลองแบบเปรียบเทียบที่ทำซ้ำได้

เก็บ input, environment, analyzer version และ workload ให้คงที่ แล้วเปรียบเทียบ artifact ก่อนและหลังป้องกัน

01

BASELINE

สำรอง build ต้นฉบับ บันทึก hash และรัน audit พร้อม --report

02

DEFEND

รันบนสำเนา ใช้ seed และ intensity ที่บันทึกไว้ แล้วเก็บ defend report

03

VERIFY

ตรวจ invariants และ functional workload ไม่ใช่ดูเพียงขนาดไฟล์หรือ token estimate

04

COMPARE

รัน analyzer เดียวกันในสภาพแวดล้อมเดียวกัน แล้วบันทึกข้อจำกัดและผลลัพธ์ที่สังเกตจริง

02 / สถานการณ์

สามจุดเริ่มต้นสำหรับการประเมิน

ตัวอย่างต่อไปนี้เป็นแผนทดลอง ไม่ใช่ผลการทดสอบที่รันไว้แล้ว

JS / ELECTRON

ตรวจ semantic evidence

บันทึกจำนวนเส้นทางที่ analyzer สรุปได้, decoy attribution, source-map exposure และผล functional tests

NATIVE / WASM

ตรวจ resource behavior

สังเกต parser limits, interface truncation, exports, format validity และ runtime compatibility

DATA / MODELS

ตรวจ format integrity

ตรวจ schema หรือ tensor data, metadata handling, analyzer errors และการเปิดไฟล์ด้วย runtime ปกติ

Reproduce / Local

เริ่มรายงานชุดแรก

ปรับ input และ protected output ให้ตรงกับโครงการของคุณ อย่ารันทับไฟล์ต้นฉบับ และอย่าตีความค่าประมาณเป็นผลวัดจริง

axobfus audit ./dist \
  --report ./reports/audit.html

axobfus defend ./dist \
  --report ./reports/defend.html

axobfus verify ./dist.protected ./dist
03 / ตรวจทาน

สิ่งที่ควรอยู่ในบันทึกผล

มิติหลักฐานที่เก็บข้อควรระวัง
ExposureAudit report, source-map และ symbol findingsจำนวน finding ไม่ได้เท่ากับความเสี่ยงเสมอไป
Analyzer costเวลา, ขั้นตอน, โทเคนที่วัดจากการรันจริงแยกค่าประมาณจากค่าที่วัด และระบุโมเดลกับเวอร์ชัน
Decoy effectข้อสรุปที่คลาดเคลื่อนและหลักฐานที่ analyzer เลือกไม่อ้างผลกับ analyzer ที่ไม่ได้ทดสอบ
CorrectnessVerification, functional tests, format validationต้องครอบคลุม workload ของผลิตภัณฑ์ ไม่ใช่เฉพาะตัวอย่าง

Defensive Counter-REA toolkit สำหรับ artifact ที่คุณเป็นเจ้าของหรือได้รับอนุญาต
